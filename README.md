## Featured projects

### 🌐 [NetOps Gateway](https://github.com/zaheenqrahman/Network-Operations-Gateway-Health-Compliance)
REST API that pulls live Cisco Meraki data, checks network health and device compliance, and serves it as JSON. Token-protected, tested with pytest, and auto-deployed to Azure App Service through GitHub Actions.
`Python` `Flask` `Meraki API` `Azure` `CI/CD`

### 🏗️ [DataCenterModel](https://github.com/zaheenqrahman/DataCenterModel)
Data center resilience simulator. Describes the network and power feeds in one YAML file, breaks devices, links or feeds, and finds the single points of failure. Tested with pytest, and built as a homelab project on VirtualBox VMs.
`Python` `NetworkX` `YAML` `pytest` `Homelab`

### 📺 [smart-tv-privacy](https://github.com/zaheenqrahman/smart-tv-privacy)
Hardened a Fire TV Stick 4K over ADB by disabling 40+ ad and telemetry packages. Every change is reversible, with pre-change snapshots and a tested rollback script.
`Bash` `ADB` `Android` `Privacy`

###  🏢  [Active Directory Lab](https://github.com/zaheenqrahman/active-directory-lab)
Worked on a hands-on Active Directory lab in VirtualBox: a Windows Server domain controller, a domain-joined Windows 11 client, 5-10 bulk users created with PowerShell, a fine grain password policy, and a Group Policy screen lock.
`VirtualBox` `Windows Server` `PowerShell` `Group Policy` `Domain Controller`
